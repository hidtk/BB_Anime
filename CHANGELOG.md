# История версий

## 1.1.0
* Поиск видео во всех фреймах страницы, включая чужие (cross-origin): верхний фрейм
  собирает данные с дочерних и отдаёт попапу единый список видео.
* Горячие клавиши, нажатые в верхнем документе, доходят до фрейма с субтитрами.
* В попапе появилась диагностика: сколько фреймов проверено и в скольких есть видео.
* Субтитры из памяти сайта больше не «прилипают» к фрейму без видео.

## 1.0.0
* Первая версия: SRT и ASS/SSA, кодировки UTF-8/UTF-16/windows-1251, оверлей в Shadow DOM,
  синхронизация, сдвиг тайминга, полноэкранный режим через Popover API, drag & drop,
  настройки в chrome.storage.sync, запоминание файла для сайта.
