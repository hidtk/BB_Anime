# BB_Anime — субтитры поверх видео (Chrome-расширение)

[![Тесты](https://github.com/hidtk/BB_Anime/actions/workflows/ci.yml/badge.svg)](https://github.com/hidtk/BB_Anime/actions/workflows/ci.yml)

Накладывает ваши файлы **.srt** и **.ass/.ssa** поверх любого HTML5-видео в браузере:
anidb.app, YouTube, локальные файлы — где угодно, включая плееры внутри фреймов.
Сборка не нужна: папку кладёте на диск и подключаете в Chrome в режиме разработчика.

Зачем: смотреть аниме с английской озвучкой и английскими субтитрами, когда на сайте
субтитров нет, а файл вы нашли сами (Animetosho, OpenSubtitles, Kitsunekko).

## Возможности

* SRT и ASS/SSA; курсив, жирный, переносы строк; ASS-теги `{\pos}`, `{\fad}` и прочие вырезаются.
* Кодировки UTF-8 (в том числе с BOM), UTF-16, windows-1251 — без кракозябр.
* Видео ищется само: появляется позже загрузки страницы, пересоздаётся при смене серии,
  лежит внутри Shadow DOM или в чужом (cross-origin) фрейме — оверлей найдёт и переедет.
* Работает в полноэкранном режиме, в том числе когда сайт разворачивает сам элемент `<video>`.
* Подстройка тайминга кнопками и горячими клавишами, сдвиг живёт до перезагрузки вкладки.
* Настройки размера шрифта, отступа снизу, подложки и обводки — применяются мгновенно.
* Запоминание последнего файла для сайта с автоподхватом.
* Поиск на opensubtitles.com: какие языки есть для конкретной серии — и загрузка
  выбранных субтитров одной кнопкой.
* Никаких внешних запросов, аналитики и удалённого кода. Разрешения: `storage`,
  `activeTab`, `scripting`.

## 1. Установка (5 минут, один раз)

**Шаг 1.** Скачайте репозиторий: зелёная кнопка **Code** → **Download ZIP** → распакуйте
в постоянное место, например `Документы\BB_Anime`. Папку после установки не удалять
и не переносить — Chrome грузит расширение прямо из неё.

**Шаг 2.** В адресной строке Chrome: `chrome://extensions`
(то же самое: меню «⋮» → **Расширения** → **Управление расширениями**).

**Шаг 3.** Включите тумблер **«Режим разработчика»** (*Developer mode*) справа вверху.

**Шаг 4.** Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) слева вверху.

**Шаг 5.** Укажите папку **`extension`** — ту, внутри которой лежит `manifest.json`.

**Шаг 6.** Закрепите иконку: значок «пазл» справа от адресной строки → булавка
рядом с «Субтитры поверх видео».

**Шаг 7.** Вкладки, открытые **до** установки, перезагрузите (F5).

## 2. Как пользоваться

1. Откройте серию, нажмите **Play** — плеер должен появиться на странице.
2. **Перетащите** файл `.srt` / `.ass` мышкой прямо на видео (или иконка расширения →
   «Загрузить субтитры»).
3. Текст появится внизу видео. Полный экран — субтитры остаются.
4. Спешат или отстают — правьте сдвиг.

### Горячие клавиши (работают и в полноэкранном режиме)

| Клавиша | Действие |
|---|---|
| **G** | сдвинуть субтитры на 0,5 с раньше |
| **H** | сдвинуть на 0,5 с позже |
| **Shift + G** / **Shift + H** | то же шагом 5 с |
| **J** | сбросить сдвиг |
| **K** | подстроить субтитры по звуку |

Клавиши не срабатывают, когда вы печатаете в поле ввода на сайте.

### Подгонка по звуку

Если субтитры идут не в такт (файл сделан под другой релиз), не обязательно
ловить сдвиг вручную. Кнопка **«🎧 Подстроить по звуку»** в попапе или клавиша
**K**: расширение слушает звук видео, отмечает, в какие секунды кто-то говорит,
и сравнивает этот рисунок с ритмом реплик в файле. Сдвиг, при котором две
дорожки совпадают лучше всего, и есть ответ — он применяется сам.

Слушает около сорока секунд (раньше, если совпадение уже уверенное; дольше
полутора минут — нет). Видео должно играть, а вкладка быть открытой; окно
попапа можно закрыть. Если в этом куске почти не говорят или субтитры вообще
от другой серии, расширение так и скажет и ничего не тронет.

### Откуда берутся субтитры

Расширение ищет в двух местах и начинает с того, что лучше подходит аниме.

**AnimeTosho** — основной источник. Это агрегатор аниме-релизов, который
вытаскивает из них дорожки субтитров и выкладывает отдельными файлами. Ключ не
нужен, а у каждой раздачи проставлены номера аниме и серии из базы AniDB,
поэтому серия находится точно, а не подбором по названию. Файлы там лежат
сжатыми в `.xz` — расширение распаковывает их само, встроенным распаковщиком
LZMA2, потому что браузер этот формат не понимает.

**OpenSubtitles** — запасной. Он отвечает расширению `403` (защита от ботов не
пропускает запросы с адресом `chrome-extension://`), поэтому расширение
открывает одну фоновую вкладку сайта и работает через неё.

### Поиск субтитров на OpenSubtitles

Не нужно ходить по сайту руками: иконка расширения → **«Найти субтитры на OpenSubtitles»**
→ название сериала, сезон и серия → **«Найти языки»**.

Ещё быстрее — кнопка **«⚡ Авто: найти и включить»**: расширение само читает
со страницы название, сезон и серию, ищет субтитры и накладывает лучший вариант
на выбранном языке.

Под капотом расширение просто запрашивает нужные страницы opensubtitles.com
(поиск сериала → страница сериала → список субтитров серии) и разбирает ответ.
Сервер отдаёт таблицу целиком, поэтому листать её не нужно. Если сериала нет
в базе или в указанном сезоне серия не нашлась, пробуются другие подходящие
сериалы, первый сезон и прямой поиск «название S01E03». Показывается список:
язык, сколько вариантов субтитров для этой серии, самый скачиваемый релиз. Кнопка **«Взять»** скачивает субтитры и сразу накладывает
их на видео в соседней вкладке; **«открыть»** ведёт на страницу субтитров, если
хочется выбрать конкретный релиз руками.

Тонкости: сайт скачивает файлы под вашей сессией, поэтому дневной лимит скачиваний
— его, а не расширения. Если вместо файла приходит архив `.zip` или страница
с лимитом, расширение честно об этом скажет — тогда качайте вручную и перетаскивайте
файл на видео. Ключ API не нужен: страницы читаются вашим же браузером, под
вашей сессией. Для этого в манифесте есть единственное разрешение на домен —
`https://www.opensubtitles.com/*`. Если запрос почему-то не проходит,
расширение открывает вкладку сайта и работает через неё.

### Настройки (иконка расширения)

* **Размер шрифта** — в процентах от высоты видео, поэтому сам масштабируется в фуллскрине.
* **Отступ снизу** — поднять субтитры над панелью плеера.
* **Подложка** и **обводка** — читаемость на любом фоне.
* **Запоминать файл для сайта** — субтитры вернутся после перезагрузки страницы.
  Кнопка «Убрать субтитры» очищает память.

Если видео на странице несколько (реклама, превью) — в попапе появится список выбора;
видео из фрейма помечено словом «во фрейме».

## 3. Быстрая проверка

1. Любой ролик на **YouTube**, нажать Play.
2. Перетащить на видео `тестовые-субтитры/пример.srt`.
3. На 1–3-й секунде — «First line of the test.», на 3,5–6-й — курсив с переносом строки.
4. Полный экран, затем **H** пару раз — текст поедет позже.
5. `пример.ass` проверяет ASS-теги, `пример-windows-1251.srt` — русскую кодировку.

## 4. Если субтитров не видно

| Симптом | Что делать |
|---|---|
| Попап: «Нет связи со страницей» | Обновить вкладку (F5) — расширение поставили позже, чем открыли страницу |
| Попап: «Видео на странице не найдено» | Сначала нажать Play (на многих сайтах `<video>` создаётся только после запуска), затем открыть попап заново. В строке диагностики видно, сколько фреймов проверено |
| Текст не совпадает с речью | Рассинхрон файла: клавиши **G** / **H**. Если расхождение растёт по ходу серии — файл под другую версию, берите другой |
| Субтитры закрывают панель плеера | Увеличить «Отступ снизу» в настройках |
| Сменили серию — субтитров нет | Оверлей переедет на новый плеер сам, но файл для новой серии нужен свой |

## 5. Как устроено

```
extension/
├── manifest.json        — Manifest V3
├── icons/
└── src/
    ├── subparse.js      — разбор SRT и ASS/SSA, определение кодировки
    ├── opensubs.js      — ссылки и разбор страниц opensubtitles.com
    ├── osnet.js         — сам поиск серии: запросы, подбор названия, скачивание
    ├── subzip.js        — распаковка .zip с субтитрами
    ├── subsync.js       — подгонка субтитров по звуку (корреляция дорожек)
    ├── tosho.js         — поиск и разбор раздач на animetosho.org
    ├── unxz.js          — распаковка .xz (LZMA2) без библиотек
    ├── content.js       — поиск <video>, оверлей в Shadow DOM, синхронизация, фреймы
    └── popup.html/.css/.js — панель управления
tests/                   — юнит-тесты, сквозные тесты и тестовые страницы
tools/make-icons.py      — генератор иконок
.github/workflows/ci.yml — прогон обоих наборов тестов на каждый push
```

Решения, которые важны на «сложных» сайтах:

* **Свой оверлей, а не `<track>`/WebVTT** — кастомные плееры часто прячут нативные дорожки.
* **Shadow DOM** — стили сайта и косметические фильтры блокировщиков не могут сломать
  или скрыть слой с субтитрами.
* **MutationObserver + перехват медиа-событий в фазе capture** — видео находится, даже если
  появляется через несколько секунд, и оверлей переезжает на новый `<video>` при смене серии.
* **Content script во всех фреймах**: верхний фрейм собирает данные с дочерних через
  `postMessage` и отдаёт попапу единый список, поэтому плеер в чужом фрейме тоже виден.
  Горячие клавиши, нажатые в верхнем документе, доезжают до фрейма с субтитрами.
* **`timeupdate` + `requestAnimationFrame`** — плавно, без рывков; на паузе цикл притормаживает.
* **Полный экран через Popover API (top layer)** — работает даже когда сайт разворачивает
  сам `<video>`, внутрь которого ничего вставить нельзя.
* **`pointer-events: none`** и максимальный z-index — клики по плееру не перехватываются.

## 6. Тесты

Два набора, оба гоняются в CI на каждый push (вкладка **Actions**).

**Юнит-тесты — 71 проверка, без браузера и без зависимостей.** Пайплайн «байты → текст →
реплики → показ»: кодировки (UTF-8, BOM, UTF-16, windows-1251), разбор SRT и ASS,
экранирование, незакрытые теги, таймкоды без миллисекунд, выбор активной реплики
при перемотке и сдвиге, сборка ссылок и группировка языков для opensubtitles.com,
распознавание архива или страницы-заглушки вместо файла, целостность манифеста.

```bash
node tests/unit.js
```

**Сквозные тесты — 52 проверки в реальном Chromium** (Playwright): геометрия оверлея,
клики сквозь субтитры, сдвиг и горячие клавиши, полный экран (и контейнера, и самого
`<video>`), пересоздание плеера при «смене серии», Shadow DOM, cross-origin фрейм,
drag & drop, восстановление из памяти, разбор таблицы результатов opensubtitles.com
с пагинацией, панель поиска в попапе, отсутствие ошибок в консоли.

```bash
cd tests
npm i playwright && npx playwright install chromium
sh make-video.sh          # тестовый ролик, нужен ffmpeg
node server.js &          # локальный сервер с поддержкой Range-запросов
node run.js               # на Linux без экрана: xvfb-run -a node run.js
```

## 7. Чего нет в этой версии

Автопоиска субтитров по API OpenSubtitles, распознавания речи, двойных субтитров EN + RU.
